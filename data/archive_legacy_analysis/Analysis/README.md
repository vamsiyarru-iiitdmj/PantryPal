# PantryPal cleaned recipe data

Generated by `build_recipe_data.py`. Source ZIP remains unchanged.

- `recipes_clean.csv`: translated recipe catalog and app filters.
- `ingredients.csv`: canonical ingredient catalog, category seed, and staple flag.
- `ingredient_aliases.csv`: observed translated names and parenthetical aliases.
- `recipe_ingredients.csv`: parsed recipe-to-ingredient rows.
- `recipe_ingredient_tuples.csv`: lean recipe / quantity / ingredient relation.
- `ingredient_recipes.csv`: reverse ingredient-to-recipe lookup.
- `ingredient_types_needing_review.csv`: conservative category exceptions, sorted by use.
- `ingredient_alias_conflicts.csv`: aliases attached to multiple ingredients; review before mapping them at runtime.
- `ingredient_type_units.csv` and `units.csv`: units observed in the source, grouped by ingredient type.
- `ingredient_parse_needs_review.csv`: ambiguous machine-translated ingredient phrases retained for review.
- `recipe_rejects.csv` and `data_quality_report.json`: reconciliation evidence.

Category labels are seed metadata inferred from ingredient text; review the exceptions before enforcing category-specific inventory unit rules.
